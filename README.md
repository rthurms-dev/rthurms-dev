## 🚀 Projetos

### 🍕 Pizzaria Chama Nós

Trabalho de banco de dados da faculdade. É um sistema de pedidos de pizzaria com banco relacional de 9 tabelas rodando direto no navegador, usando SQLite (sql.js). Tem uma tela para o cliente fazer o pedido e um painel de administrador, e as duas ficam sincronizadas na hora. Quando um pedido é entregue, o estoque de ingredientes é descontado automaticamente. O painel também tem um console de SQL com consultas prontas, como vendas por período e sabor mais pedido.

**Tecnologias:** JavaScript, SQL, SQLite, HTML5, CSS3

🔗 [Repositório](https://github.com/rthurms-dev/pizzaria-chama-nos) | [Demo](https://rthurms-dev.github.io/pizzaria-chama-nos/)

### 🥗 NutrIA

Site de saúde e nutrição com calculadoras de IMC, ingestão de água e gasto calórico, conteúdo informativo, cadastro e login de usuários e um chat com IA que só responde sobre saúde. A chave da API de IA não fica no código do site: o navegador chama um Cloudflare Worker, que guarda a chave e faz a requisição.

**Tecnologias:** JavaScript, HTML5, CSS3, Bootstrap 5, Supabase, Cloudflare Workers

🔗 [Repositório](https://github.com/rthurms-dev/nutrIA-chat) | [Demo](https://rthurms-dev.github.io/nutrIA-chat/)
